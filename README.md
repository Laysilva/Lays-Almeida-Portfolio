# Lays Almeida — Portfólio profissional

Portfólio multilíngue em React + Vite, com versões em português brasileiro (PT-BR), português de Portugal (PT-PT) e espanhol (ES).

## Requisitos
- Node.js LTS
- npm

## Executar localmente
```bash
npm install
npm run dev
```
Abra o endereço local mostrado pelo Vite.

## Gerar versão de produção
```bash
npm run build
npm run preview
```

## Publicar na Vercel
1. Crie um repositório novo no GitHub chamado `lays-almeida-portfolio`.
2. Envie os ficheiros deste projeto para o repositório.
3. Na Vercel, importe esse repositório.
4. Use as definições padrão do Vite e publique.
5. A Vercel fornecerá uma URL pública. O domínio próprio pode ser decidido mais tarde.

## Antes de divulgar
- Confirmar detalhes técnicos do site do Theatro Municipal e do Desenvolve Cultura RJ.
- Confirmar a forma de apresentar o vínculo atual como Vivo / Vita e o nome oficial da entidade empregadora.
- Confirmar links públicos de GitHub e currículo em PDF.
- Rever o conteúdo dos três idiomas.
- Verificar se as imagens e os materiais usados nos cases podem ser divulgados.
